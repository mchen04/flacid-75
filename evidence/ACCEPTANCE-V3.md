**Environment note.** The build session ran in a sandbox that forbids listening sockets, Docker and WebKit. Headless Chromium launches only in single-process mode, so the browser checks run against a virtual server (`scripts/virtual-server.mjs`: the production build served through request interception) with one browser per test (`tests/e2e/fixtures.ts`, `VIRTUAL_SERVER=1`). WebKit checks are committed and runnable outside the sandbox but were not executed here. The gate check that needs a real server is covered against production by `scripts/deployment-check.mjs`.
