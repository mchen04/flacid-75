# Blind comparison gate

Each round pairs one of our screens with one competitor screen. Both panels are resized to the
same canvas on the same neutral ground, named by random ids and shuffled, so the reviewer cannot
tell which is which. A reviewer with no knowledge of the project reads exactly two images and
names the preferred screen for each of four dimensions: quality, theme, aesthetics, polish.
`key.json` in each round folder maps the ids back.

References used, all real in-app screens rather than marketing frames: streaks-app-0,
cronometer-app-2, duolingo-app-1, finch-app-3, macrofactor-app-1, strong-app-0.

## What the reviewers still say about our screens

Recorded because it is honest, not because it is resolved: the "Tap to log" circles and the tab bar
name the same four habits within one viewport. That is deliberate. The tiles log a habit in one tap
from launch, which the tap budget requires; the tabs open each habit's own screen, which the brief
requires. Both were kept and the row was labelled rather than dropping either.
