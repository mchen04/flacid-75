# Competitor reference captures

These files contain official website and App Store reference images for Cronometer, MacroFactor, Streaks, Strong, Finch, and Duolingo.
Each `*-source.json` records the published screenshot URLs for that app.
Each `*-app-N.jpg` corresponds to a screenshot in that source record.
The unnumbered PNGs capture official website pages.

The captures support the design references in the [ledger](../LEDGER.md#competitor-references).
They do not prove native installation, actual use, or a blind comparison win.
Physical native-app use and the required piece-by-piece comparisons remain unfinished.
The [character comparison record](../blind/reviews.md) separately documents the two limited mascot reviews.

These references are evidence only. `.vercelignore` excludes this directory from deployment.
The shipped mascot and interface illustrations come from the repository's hand-authored SVG sources.
